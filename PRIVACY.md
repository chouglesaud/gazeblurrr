# Privacy Policy — GazeBlurrr

**GazeBlurrr collects nothing.** No analytics, no accounts, no servers, no tracking.

- **Pictures and videos** are checked by a model that is inside the extension. They are never uploaded anywhere.
- **Your settings** (the websites you protect, strength, timer, and pictures you marked safe) are stored with `chrome.storage.local` on your computer. They are not synced and never transmitted.
- **Network use:** the extension itself makes no requests of its own. To check a picture it asks the browser for the same image the page is already showing.
- **Permissions:** `<all_urls>` is needed so protection can work on any website you switch on, and to read the pictures on it. On websites you have not switched on, the extension does nothing. `storage` saves your settings. `offscreen` keeps the detector loaded in memory so checks are fast.

The code is open source, so you can verify every sentence above.

Questions: open an issue on the project's GitHub page.
